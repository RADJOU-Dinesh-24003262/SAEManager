À propos de SAE Manager

SAE Manager est un site vous permettant de planifier vos SAE à travers l’ajout de tâches, de listes et d’objectifs sous la forme d’un tableau avec un graphe de votre avancement tout au long de votre projet.

Vous êtes professeurs ? SAE Manager vous permet de créer une plateforme en lien avec vos SAE et de pouvoir voir l’avancement de vos étudiants.

Vous êtes clients ? Vous pouvez vous aussi voir comment avancent les étudiants et les aider dans leurs projets.

SAE Manager a été pensé à la demande de Mme Sakli pour centraliser et ordonner tous les livrables et informations. Ce site permet d'optimiser au mieux le temps de travail de toutes les parties.
