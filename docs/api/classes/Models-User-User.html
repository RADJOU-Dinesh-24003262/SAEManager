fetchDataFromDatabase()

fetchDataFromDatabase(string  $email) : void

Fetches user data from the database using their email address.

This method queries the database for a user record that matches the provided email address. If a user is found, it populates the current object’s properties with the retrieved data, including personal information and, if applicable, student-specific details.

If no user is found or a database error occurs, an ExceptionFetchDataBD is thrown.

Parameters

string $email

The email address of the user to fetch.

Throws

\includes\exception\ExceptionFetchDataBD
